АГЕНТЫ ДЛЯ OPENCODE (13 штук)
==============================
Файлы .md — каждый файл один агент, имя файла = имя агента.
Ставятся окном «Управление базой» (галочка «Агенты») в папку
agents/ настроек opencode. Вызов: @имя.

Состав:
  iskatel        — поиск по коду, только чтение
  dokop          — документация и интернет
  proektirovschik — план работы и список проверок
  programmist    — пишет код по плану
  proveryalschik — запускает тесты и проверки
  retsenzent     — ревью глазами, без правок
  ohrannik       — секреты и безопасность
  dizayner       — интерфейсы
  bazy           — таблицы, миграции, медленные запросы
  devops         — сборка, деплой, дежурство
  golosovoy      — команды голосом (мостик к tools/voice)
  provodnik-pk   — компьютер через мост pc_* (всё через ask)

Правила для всех:
  - модель не вписана: агент работает на текущей модели opencode;
  - опасное запрещено правами прямо в файле (рецензент и охранник
    даже команд не запускают);
  - связка работы: проектировщик → программист → проверяльщик → рецензент.
